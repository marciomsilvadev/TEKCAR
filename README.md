# TECK CAR — Mecânica de Alta Precisão (Porto Alegre)

Aplicação 100% Frontend (Static Site) desenvolvida com React, Tailwind CSS e Framer Motion para a oficina automotiva TECK CAR em Porto Alegre - RS.

## 🚀 Publicação no Render (Static Site)

O projeto está configurado para deploy estático imediato no **Render**:

- **Type**: Static Site
- **Root Directory**: `frontend`
- **Build Command**: `npm install && npm run build`
- **Publish Directory**: `build`

> Não requer backend, FastAPI, MongoDB, variáveis de ambiente ou dependências externas de API.

---

## 🛠️ Comandos Locais

Dentro do diretório `frontend`:

```bash
# Instalação limpa de dependências
npm install

# Executar servidor de desenvolvimento
npm start

# Gerar build otimizada para produção
npm run build
```

## 📐 Estrutura e Identidade Visual

- **Paleta de Cores**: Fundo principal `#0A0D12`, nuances grafite/azul-marinho (`#0F141C`, `#141B24`), cinza titânio e vermelho de precisão cirúrgica (`#E5252A`).
- **Tipografia**: Barlow Condensed / Outfit (títulos/display), DM Sans (corpo editorial) e JetBrains Mono (especificações e dados técnicos).
- **Hero Cinematográfico**: Background com vídeos reais da oficina fornecidos pelo proprietário, alternância suave, tratamento escuro e tipografia editorial de alto contraste.
- **Fotografias Autênticas**: Imagens locais em `public/images/` capturando elevadores, box de atendimento, motor e fachada da Av. Vicente Monteggia, 2211.
